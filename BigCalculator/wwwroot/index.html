BigCalculator - Arbitrary Precision Calculator

BigCalculator.org is a free online arbitrary-precision calculator that handles numbers of virtually any size. Perform addition, subtraction, multiplication, division, powers, roots, logarithms, and trigonometric functions with precision up to millions of bits.

Features

  • Arbitrary precision arithmetic - no limits on number size
  • Support for decimal, binary, and hexadecimal formats
  • Operations: +, -, x, /, powers, roots, sqrt, log2, log10, ln, exp, sin, cos, tan
  • Adjustable precision from 16 bits to 1 million bits
  • Calculation history with result transfer
  • Works offline as a Progressive Web App

Powered by BigFloat

Built on the BigFloat C# library for arbitrary-precision floating-point arithmetic. Learn more about BigFloat.
